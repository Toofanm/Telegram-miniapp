# راهنمای نصب: Humanizer
شخصی‌سازی‌شده برای EditorFarzad

## روش ۱: Claude.ai یا اپ دسکتاپ
1. فایل `editorfarzad-humanizer.skill` رو دانلود کن (یا داخل اپ دکمه‌ی Save skill رو بزن).
2. برو به Settings ← Capabilities ← Skills و فایل رو آپلود کن (اگه فقط zip قبول کرد، پسوند رو به .zip تغییر بده).
3. مطمئن شو Code execution روشنه و اسکیل فعاله.

## روش ۲: Claude Code
```bash
unzip editorfarzad-humanizer.skill -d ~/.claude/skills/
```
بعد Claude Code رو دوباره باز کن. اسکیل با دستور `/editorfarzad-humanizer` یا خودکار فعال می‌شه.

بنویس: «این متن رو humanize کن» و متن رو بچسبون. برای هماهنگی با لحن خودت، ۲-۳ پاراگراف از نوشته‌هات رو هم بفرست.
