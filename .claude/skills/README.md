# مهارت‌های پروژه مینی‌اپ تلگرام

این مسیر برای اسکیل‌های اختصاصی و مشترک پروژه است.

## محل بارگذاری

پوشه‌های اسکیل را در همین مسیر قرار دهید؛ هر اسکیل باید پوشه مستقل و فایل `SKILL.md` در ریشه خودش داشته باشد:

- `uiux-pro-max/SKILL.md`
- `firecrawl-research/SKILL.md`
- `persian-humanizer/SKILL.md`
- `supplement-miniapp-project/SKILL.md`

## روش بارگذاری

فایل ZIP بسته آماده‌شده را ابتدا روی دستگاه خود استخراج کنید. سپس محتویات پوشه `.claude/skills/` استخراج‌شده را در همین مسیر GitHub بارگذاری کنید. خود فایل ZIP را به‌تنهایی اینجا قرار ندهید؛ GitHub آن را به‌صورت خودکار استخراج و به اسکیل تبدیل نمی‌کند.

پس از بارگذاری، ساختار باید شامل چهار پوشه بالا و فایل `SKILL.md` داخل هرکدام باشد.

## توجه

این شاخه برای آماده‌سازی اسکیل‌ها ساخته شده و هنوز وارد `main` نشده است. پس از بارگذاری و بررسی ساختار، تغییرات از طریق Pull Request قابل ادغام خواهند بود.
